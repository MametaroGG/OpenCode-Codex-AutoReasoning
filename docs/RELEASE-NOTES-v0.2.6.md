# v0.2.6 — ローカル計測ログ

**Language:** 日本語 · [English](RELEASE-NOTES-v0.2.6.en.md)

`measurement: true`を設定すると、判定メタデータとホスト発行の使用量を上限付きのローカルログへ記録できます。既定は`false`で、外部送信は行いません。

## 記録されるものとされないもの

- 記録: 時刻、セッション参照（sha256先頭16文字）、難易度、推奨／選択思考量、選択方針、理由、キャッシュ命中、判定時間、判定モデル、開発モデルID、設定変更の有無、ホスト発行のトークン／費用。
- 保存しない: ユーザー指示、直前の指示、展開後ソース、システム指示、ツール結果、ファイルパス、認証情報、生のセッションID。

保持件数は`maxEntries`（既定256、上限4096）のリング形式で、アンロード時に消去されます。読み取りは`auto_reasoning_status`と`auto-reasoning` RPCの`measurement`フィールドのみです。

## 限界

このログは選択と使用量を後から突き合わせるためのもので、**節約効果の実証ではありません**。セッション累計の使用量から個々の呼び出しを分離できないこと、比較対象を同じ条件で取っていないこと、判定呼び出し自体の使用量がAPIから返らないことは変わりません。詳細は[検証記録](VALIDATION.md#ローカル計測--measurement)を参照してください。

## 変更なし

32のAPI modelIDへのモデル別ポリシー、Luna判定prompt、SDK 2.3.2対応、テスト151件の結果は0.2.5から変更ありません。
